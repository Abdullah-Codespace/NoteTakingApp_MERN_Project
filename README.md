# NoteTaking App

A full stack note taking web application built using the MERN stack. The project allows users to create, manage, edit, and delete notes through a responsive and interactive user interface. The frontend was developed using React and Tailwind CSS, while the backend was built using Node.js, Express.js, MongoDB, and Redis for backend functionality and caching.

The application is currently deployed on Render for development and testing purposes, with future plans to deploy and scale the project using AWS cloud services to further improve deployment, scalability, and overall system architecture.

## Tech Stack

### Frontend

* React.js
* Tailwind CSS
* Lucide React
* React Hot Toast

### Backend

* Node.js
* Express.js
* MongoDB
* Redis

### Deployment

* Render
* Planned AWS deployment
